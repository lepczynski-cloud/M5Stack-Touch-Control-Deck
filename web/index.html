READY TO TRY IT?

From browser to device.

Connect your CoreS3 SE via a USB data cable. No local build or setup required for the web installer.

01

Connect your M5Stack

Use a USB-C cable that supports data, not only charging.

02

Choose update or factory install

Update preserves your settings only if you do not choose Erase device. Factory installation resets configuration.

03

Pair Bluetooth and select your OS

Choose Windows, macOS or Linux GNOME on the device after pairing.

⌘
On macOS?

For near-instant action triggering, configure native Shortcuts once and enable Fast mode in the device portal.
