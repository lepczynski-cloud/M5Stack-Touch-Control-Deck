WHAT IT DOES

Small device. Useful shortcuts.

One screen for the things you reach for every day. Swipe between pages and make it yours.

Your favorite apps

Six editable buttons for websites and everyday tools. Launch a URL with a single touch.

ChatGPTClaudeGemini

Media & volume

Play, pause, skip or mute. The optional Scroll Unit adds a physical volume knob.

Windows shortcuts

Task Manager, screenshots, File Explorer, desktop and lock screen. No extra app required.

Two time zones

See local time and another city. Synchronize over Wi-Fi and keep time using the RTC.

Bluetooth HID

Windows recognizes a standard wireless keyboard. No Python service or USB cable in daily use.

Local configuration

Change buttons, brightness and time zones through a local web portal on the device.

WEB FLASHER

From browser to device.

No local compilation for visitors. Just the correct board, a USB data cable and a compatible desktop browser.

01

Connect your device

Plug your M5Stack CoreS3 SE into your computer with a USB-C data cable. The battery and Scroll Unit are optional.

02

Install in the browser

Use a compatible desktop browser over HTTPS, click Install, and select your device's USB serial port.

03

Pair with Windows

After installation, add “M5 Control Deck” in Windows Bluetooth settings and start using your shortcuts.

i
Before you start

Only for M5Stack CoreS3 SE. Flashing changes device firmware and can erase saved settings. The controller's keyboard actions target Windows 10/11.
